# PhD Portfolio — Manisha Muduli

A static portfolio website featuring photonics research, publications, projects, poster presentations, a CV, professional milestones, and news coverage.

## Website source

All deployable HTML, CSS, JavaScript, images, and PDFs are in `docs/`. No build step or package installation is required.

## Preview locally

Serve `docs/` using a static web server. For example, with Python installed:

```sh
python -m http.server 8000 --directory docs
```

Open http://localhost:8000.

## GitHub Pages

When ready to make the portfolio public, choose **Settings → Pages → Deploy from a branch → main → /docs** in GitHub.

Pages has not been enabled as part of the repository setup. Uploading the source to a private repository does not change the privacy of the existing Sites deployment.

## Source scope

This repository contains a copy of the website from `portfolio-site/dist`. Unrelated résumé drafts, local tools, temporary files, deployment archives, and Sites-specific repository configuration are excluded.
